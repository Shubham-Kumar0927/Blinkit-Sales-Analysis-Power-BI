# Blinkit Sales Analysis Dashboard | Power BI

## 📌 Project Overview
This project focuses on analyzing Blinkit sales data using Power BI to understand sales performance, product distribution, outlet characteristics, and customer preferences. An interactive dashboard was developed to track key metrics and provide business insights through data visualization.

## 🎯 Objectives
- Analyze overall sales performance and outlet-wise sales.
- Understand product distribution based on item type and fat content.
- Compare sales across outlet locations and outlet sizes.
- Analyze outlet establishment trends over the years.
- Build an interactive dashboard for business decision-making.

## 📊 Key KPIs
- **Total Sales:** $1.20M
- **Average Sales:** 141
- **Number of Items:** 8,523
- **Average Rating:** 4

## 📈 Dashboard Features
- KPI cards for key business metrics.
- Sales trend analysis by outlet establishment year.
- Fat content analysis.
- Item type performance analysis.
- Outlet size comparison.
- Outlet location tier analysis.
- Outlet type performance table.
- Interactive filters for outlet location, outlet size, and item type.

## 🛠️ Tools & Technologies
- Power BI
- Data Visualization
- Data Analysis
- Interactive Dashboards

## 💡 Business Insights
- Provides an overview of overall sales performance.
- Helps compare outlet performance across different location tiers.
- Identifies product categories and fat content distribution.
- Enables analysis of outlet sizes and establishment trends.
- Supports data-driven business decisions.
